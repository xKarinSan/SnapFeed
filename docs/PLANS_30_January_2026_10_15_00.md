# Plan: Unified Panel Layout - Simplify Feedback System

## Overview

Restructure the project detail page to eliminate the browser/screenshots toggle and remove UI feedback (positioned pins). The browser iframe will always be visible in the main content area, while the right panel will have two sections: General Feedback and Screenshots.

**Current State:**
- Toggle between "Browser" and "Screenshots" views
- FeedbackPanel shows UI feedback (pins) and General feedback
- Screenshots displayed in separate gallery view
- Top bar with project info

**Target State:**
- Top bar stays (unchanged)
- Browser always visible in main area (no toggle)
- Right panel with 2 sections:
  1. General Feedback (text-only feedback)
  2. Screenshots (thumbnails, click opens viewer modal)
- UI feedback (positioned pins) removed entirely

```prisma

  id         String   @id @default(uuid())

  content    String
  posX       Float?   // Unused (kept for backward compatibility)

  viewportW  Float?   // Unused
  viewportH  Float?   // Unused
  selector   String?  // Unused

  id          String       @id @default(uuid())
```

## Considerations

### Performance
- Screenshot thumbnails should be lazy-loaded if list grows large
- Consider pagination or virtual scrolling for 20+ screenshots

### Backward Compatibility
- Existing UI feedback data in database will be preserved but not displayed
- No data migration needed
- Old projects with UI feedback will still work (feedback just won't show)

### What's Removed
- Browser/Screenshots toggle buttons
- UI feedback (positioned pins on browser)
- Click-to-add-feedback on browser viewport
- UI feedback section in panel

### What's Kept
- Top bar (project info, navigation)
- MiniBrowser with screenshot capture
- General feedback (add/edit/delete)
- Screenshot viewer with annotations
- Export functionality

### Testing Approach
1. Verify top bar displays correctly
2. Verify browser is always visible (no toggle)
3. Test General feedback creation/deletion
4. Test screenshot capture → appears in panel
5. Test screenshot thumbnail click → opens viewer
6. Verify annotations still work in viewer
